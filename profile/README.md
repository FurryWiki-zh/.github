# 欢迎来到福瑞百科 👋

**福瑞百科**（FurryWiki）是一个面向中文兽迷社区的开放协作百科全书，基于 MediaWiki 构建，致力于收录、整理和分享兽人文化相关知识。

## 🌐 关于我们

- **目标**：建设一个由中文兽迷社区共同维护的权威知识库
- **平台**：基于 [MediaWiki](https://www.mediawiki.org/) 构建
- **语言**：以中文为主

## 📦 主要仓库

| 仓库 | 描述 |
| --- | --- |
| [FurryWiki-Extensions](https://github.com/FurryWiki-zh/FurryWiki-Extensions) | 福瑞百科所使用的 MediaWiki 扩展 |
| [FurryWiki-Skins](https://github.com/FurryWiki-zh/FurryWiki-Skins) | 福瑞百科所使用的 MediaWiki 皮肤 |

## 🤝 参与贡献

我们欢迎所有对兽人文化感兴趣的朋友参与贡献！无论是修复问题、改进代码还是完善文档，每一份贡献都十分宝贵。
